# Ethics

## PDF availability

The repository provides completed scores and available bibliographic metadata for **all 200 evaluated papers**. It also includes **51 unchanged PDFs** whose source copies explicitly state a Creative Commons license; the paper index records each released file's source hash and repository path. Full-text PDFs without a confirmed redistribution license are not included. Readers should follow the notice in each released PDF and the [Creative Commons license terms](https://creativecommons.org/share-your-work/cclicenses/).

## Human responsibility

PaperEval produces structured evidence and rule-level assessments for research inspection. Human researchers remain responsible for interpreting and validating results. The system's scores are not presented as editorial decisions.

PaperEval is intended to support research and exploratory analysis. It is not intended to score manuscripts for peer review, replace reviewers, generate editorial recommendations, or inform accept/reject decisions. Its outputs should be treated as supplementary research materials, not as peer reviews.
