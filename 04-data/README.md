# Data and Research Materials

This section documents the released corpus outcomes, source-paper inventory, and sample PDFs available for redistribution.

## Contents

- [Corpus audit](corpus-audit.md): corpus reconciliation and aggregate score summaries.
- [Paper-level outcomes](paper-outcomes.csv): title-free scores and processing status for the unique source papers.
- [Study scope](study-samples.md): how the released corpus relates to the broader experiment archive.
- [Data definitions](data-index.md): column definitions and release scope for the outcome table and PDF inventory.
- [Source-paper inventory](sample-paper-index.csv): 149 source-file records representing 146 unique SHA-256 hashes, with DOI and PDF-release information where available.
- [Sample PDFs](sample-papers/README.md): 29 unchanged PDFs whose source copies state a Creative Commons license; each file is checksum-verified against the inventory.
- [Experiment catalog](../03-experiments/experiment-catalog.md): study designs and results.

The outcome table contains **144 scored papers** and **two papers blocked before scoring by PDF parsing**. It omits titles, journal names, source text, and local paths. The inventory records the 149 original file entries and distinguishes the 29 PDFs released here from the 120 for which redistribution permission is not confirmed in the available copy. The repository does not include paper-level report files. See the [ethics and data-access statement](../05-ethics-access/README.md) for data handling information.
