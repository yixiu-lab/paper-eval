# Sample Papers

This directory contains 18 unchanged sample-paper PDFs whose source copies state a Creative Commons sharing license. The files are identified by checksum-based sample IDs and cross-referenced in the [sample-paper index](../sample-paper-index.csv).

The index covers all 149 source PDF inputs and provides DOI values where available. The other source PDFs are not included because their redistribution terms have not been confirmed from the available copies.

Each included PDF retains its original title page and license notice. CC BY requires attribution; CC BY-NC-ND permits sharing the unmodified work for non-commercial purposes with attribution. See the [Creative Commons license descriptions](https://creativecommons.org/share-your-work/cclicenses/) for the license terms.
