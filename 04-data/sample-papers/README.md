# Sample Papers

This directory contains 29 unchanged sample-paper PDFs whose source copies state a Creative Commons license permitting redistribution. The files are identified by checksum-based sample IDs and cross-referenced in the [sample-paper index](../sample-paper-index.csv).

The index covers all 149 source PDF inputs and provides DOI values where available. The remaining source PDFs are not included as downloadable files because their redistribution terms could not be confirmed from the available copies.

Each included PDF is unchanged and retains its original title page and license notice. The index records the license stated in each included PDF. See the [Creative Commons license descriptions](https://creativecommons.org/share-your-work/cclicenses/) for the license terms.
