# Sample Papers

This directory contains **29 unchanged PDFs** whose source copies state a Creative Commons license. Every file's SHA-256 checksum matches the corresponding entry in the [source-paper inventory](../sample-paper-index.csv). The files retain their original title pages and license notices.

The released set contains 19 PDFs marked CC BY, two marked CC BY-NC, and eight marked CC BY-NC-ND. These licenses have different conditions; consult each PDF's notice and the [Creative Commons license descriptions](https://creativecommons.org/share-your-work/cclicenses/) before reuse.

The inventory covers 149 source-file records representing 146 unique PDF hashes. DOI metadata was checked against Crossref or publisher records. The other 120 source entries are not included as downloadable PDFs because redistribution permission could not be confirmed from the available copies.
