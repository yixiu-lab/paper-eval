# Released Study Data

This folder contains de-identified, title-free outputs for the corpus audit. Each record is keyed by a checksum-derived paper identifier; source titles, PDF paths, and full text are excluded.

| File | Contents |
| --- | --- |
| [`paper-outcomes.csv`](paper-outcomes.csv) | Per-paper processing status and available total and dimension scores |
| [`study-samples.md`](study-samples.md) | Paper counts and run counts by study; samples are kept separate |

Source-paper PDFs and paper-linked full-text traces remain in the research workspace.
