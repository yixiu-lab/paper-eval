# Released Study Data

This folder contains de-identified, title-free outputs for the corpus audit. Each record is keyed by a checksum-derived paper identifier; source titles, PDF paths, and full text are excluded.

| File | Contents |
| --- | --- |
| [`paper-outcomes.csv`](paper-outcomes.csv) | Per-paper processing status and available total and dimension scores |
| [`study-samples.md`](study-samples.md) | Paper counts and run counts by study; samples are kept separate |
| [`sample-paper-index.csv`](sample-paper-index.csv) | Source IDs, DOI values where available, and PDF release status for corpus inputs |
| [`sample-papers/`](sample-papers/README.md) | Unchanged sample-paper PDFs with a sharing license identified in the source PDF |

The index covers all source inputs. It identifies which PDFs are included in the public collection and which have no sharing license confirmed from the local copy.
